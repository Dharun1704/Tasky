Tasky, the floating dock that replaces the Windows 11 taskbar, gets a search button: it opens out into Windows Search right in the dock.

> **New to Tasky? Please read [Read this first](https://github.com/Dharun1704/Tasky#read-this-first)** in the README before installing: Tasky hides the Windows taskbar while it runs (Exit Tasky always brings it back), and because it isn't code-signed, Windows SmartScreen will warn you the first time (**More info → Run anyway**).

### Downloads

| File | Size | Needs |
| --- | --- | --- |
| `Tasky-1.5.0-win-x64.zip` | ~3 MB | The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64): `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `Tasky-1.5.0-win-x64-standalone.zip` | ~65 MB | Nothing: it includes .NET |

**Updating from 1.4.0 or 1.3.0:** exit Tasky (right-click the dock → **Exit Tasky**), replace `Tasky.exe` with the one from the zip, and start it again. Your settings and pins are kept.

**New install:** unzip to a folder it can stay in (for example `%LOCALAPPDATA%\Programs\Tasky`) and run `Tasky.exe`. Windows 11, 64-bit.

### New in 1.5.0

- **Search button.** A magnifier beside Start opens Windows Search. On a dock at the bottom it widens into a search box, and what you type appears right inside it, with the results above. **Win+S** does the same. Click it again to close the search.
  - For the box to open out, the Windows search setting must be **Search box** (Settings → Personalization → Taskbar → Search). With any other choice, or a dock on another edge, the button simply opens Windows Search.
  - Don't want it? Turn it off in Tasky's settings under **System → Search button**.
- **Searching from Start looks right.** Typing in Start now shows the results centred and just above the dock, straight away, instead of low over the dock and then jumping into place.
- **Start sits closer to the dock**, with the same gap as search and the other panels.
- **The gear toggles settings.** Click it to open Tasky's settings and again to close them, with a little turn each way. With Start open, it now closes Start first, so settings no longer opens hidden behind it.

### Fixes

- The Start, search, Quick Settings and clock buttons now work while an app running as administrator (Task Manager, for example) has the focus.

### Known limitations

- Pressing **Win+S** on the keyboard while Start is already open shows search like Start's results, without the box opening out in the dock. Clicking the dock's search button works as intended.
- Windows 11 only; one dock on one display; most apps flashing for attention don't bring up the dock (permission prompts do); Quick Settings stays bottom-right for a dock on the top or sides. The full list is in the [README](https://github.com/Dharun1704/Tasky#read-this-first).
