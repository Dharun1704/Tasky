The first downloadable release of Tasky, a floating dock that replaces the Windows 11 taskbar.

> **Before you install, please read [Read this first](https://github.com/Dharun1704/Tasky#read-this-first)** in the README: Tasky hides the Windows taskbar while it runs (Exit Tasky always brings it back), and because it isn't code-signed, Windows SmartScreen will warn you the first time (**More info → Run anyway**).

### Downloads

| File | Size | Needs |
| --- | --- | --- |
| `Tasky-1.3.0-win-x64.zip` | 3.3 MB | The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64): `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `Tasky-1.3.0-win-x64-standalone.zip` | 64.5 MB | Nothing: it includes .NET |

Unzip to a folder it can stay in (for example `%LOCALAPPDATA%\Programs\Tasky`) and run `Tasky.exe`. Windows 11, 64-bit.

### New in 1.3.0

- **New settings window** in the style of Windows 11 Settings: Mica background, sidebar pages and a card per setting. It follows light and dark mode and your accent colour.
- **App icon.**
- **Start and Tasky's menus clear the dock** at any dock size, and opening the tray popup or a menu while Start is open no longer leaves it behind Start.
- **Starts sooner at sign-in**, through a Task Scheduler sign-in task. Until it starts, the normal taskbar is there instead of nothing.
- **Smoother window previews:** closing a window fades its card out and the rest re-centre; the × shows on the card under the mouse.

### Fixes

- Exiting Tasky now reliably brings the Windows taskbar back, and puts Start back where Windows had it.
- Tasky exits fully if its dock window is closed from outside, instead of lingering invisibly.
- A cancelled Windows shutdown no longer leaves you without a taskbar.
- The dock no longer stays up because a settings window is open in the background.

### Known limitations

Windows 11 only; one dock on one display; most apps flashing for attention don't bring up the dock (permission prompts do); Quick Settings stays bottom-right for a dock on the top or sides. The full list is in the [README](https://github.com/Dharun1704/Tasky#read-this-first).
