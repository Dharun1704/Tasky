Tasky, the floating dock that replaces the Windows 11 taskbar, gets a round of fixes: the dock hides only when it should, the battery icon tells the truth, and it no longer covers right-click menus. It also uses less CPU when idle.

> **New to Tasky? Please read [Read this first](https://github.com/Dharun1704/Tasky#read-this-first)** in the README before installing: Tasky hides the Windows taskbar while it runs (Exit Tasky always brings it back), and because it isn't code-signed, Windows SmartScreen will warn you the first time (**More info → Run anyway**).

### Downloads

| File | Size | Needs |
| --- | --- | --- |
| `Tasky-1.5.1-win-x64.zip` | ~3 MB | The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64): `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `Tasky-1.5.1-win-x64-standalone.zip` | ~65 MB | Nothing: it includes .NET |

**Updating from 1.5.0 or earlier:** exit Tasky (right-click the dock → **Exit Tasky**), replace `Tasky.exe` with the one from the zip, and start it again. Your settings and pins are kept.

**New install:** unzip to a folder it can stay in (for example `%LOCALAPPDATA%\Programs\Tasky`) and run `Tasky.exe`. Windows 11, 64-bit.

### Fixes

- **The dock hides only for the window you're using.** A maximized window sitting behind a smaller focused window no longer hides the dock. It hides when the focused window covers it.
- **The battery icon is right.** It now shows the correct icon for charging, normal and battery saver, instead of sometimes showing the low or saver icon while charging. The tooltip also says when battery saver is on.
- **Quick Settings opens in place.** The Wi-Fi and sound panel no longer flashes in the corner of the screen before snapping to the dock.
- **Right-click menus aren't cut off.** Long context menus that reach down to the dock now stay on top of it, so every option can be reached.

### Performance

- **Less CPU when idle.** The check for permission prompts was about half of Tasky's idle CPU. It now runs far less often and looks only at your own session, while prompts are still noticed straight away.
- The volume code no longer leaves audio objects behind every few seconds.

### Known limitations

- Pressing **Win+S** on the keyboard while Start is already open shows search like Start's results, without the box opening out in the dock. Clicking the dock's search button works as intended.
- Windows 11 only; one dock on one display; most apps flashing for attention don't bring up the dock (permission prompts do); Quick Settings stays bottom-right for a dock on the top or sides. The full list is in the [README](https://github.com/Dharun1704/Tasky#read-this-first).
