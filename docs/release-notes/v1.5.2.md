Tasky, the floating dock that replaces the Windows 11 taskbar, now works properly on a second display: put the dock on any screen and Start, search, notifications and Windows' other panels open there with it. There are also a few small fixes, and new buttons in settings.

> **New to Tasky? Please read [Read this first](https://github.com/Dharun1704/Tasky#read-this-first)** in the README before installing: Tasky hides the Windows taskbar while it runs (Exit Tasky always brings it back), and because it isn't code-signed, Windows SmartScreen will warn you the first time (**More info → Run anyway**).

### Downloads

| File | Size | Needs |
| --- | --- | --- |
| `Tasky-1.5.2-win-x64.zip` | ~3 MB | The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64): `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `Tasky-1.5.2-win-x64-standalone.zip` | ~65 MB | Nothing: it includes .NET |

**Updating from 1.5.1 or earlier:** exit Tasky (right-click the dock → **Exit Tasky**), replace `Tasky.exe` with the one from the zip, and start it again. Your settings and pins are kept.

**New install:** unzip to a folder it can stay in (for example `%LOCALAPPDATA%\Programs\Tasky`) and run `Tasky.exe`. Windows 11, 64-bit.

### New in 1.5.2

- **Exit Tasky and Close settings buttons** at the bottom of the settings sidebar.

### With the dock on a second display

- **Start and search open with the dock.** Start used to open on the main display wherever the dock was. It now opens centred on the dock's display, and search results appear there too as you type. Exiting Tasky puts Start back on the main display.
- **The Windows taskbar no longer pops up.** Tasky now hides it on every display, so moving the mouse to the bottom of a screen doesn't bring it up. This means displays without the dock have no taskbar while Tasky runs.
- **Windows' panels work.** The clock panel sits at the bottom right instead of floating part-way up the screen, and Win+P shows its full list of options instead of only a title.
- **Notifications appear at the bottom right** of the dock's display, instead of part-way up the right side.
- **Settings follows the dock.** It opens on the dock's display and moves when you pick another one, and its list of displays updates when you connect or remove one, without restarting Tasky.

### Fixes

- **Quick Settings sits closer to the dock**, with the same gap as Start.
- The Wi-Fi, volume and battery label disappears when you click the button, instead of staying under the panel.
- The tray icons popup has even space on both sides and a gap above the dock.

### Known limitations

- Pressing **Win+S** on the keyboard while Start is already open shows search like Start's results, without the box opening out in the dock. Clicking the dock's search button works as intended.
- Displays with different scaling (one at 100%, another at 150%) haven't been tested with the dock on a second display, so Windows' panels may not line up there.
- Windows 11 only; one dock on one display; most apps flashing for attention don't bring up the dock (permission prompts do); Quick Settings stays bottom-right for a dock on the top or sides. The full list is in the [README](https://github.com/Dharun1704/Tasky#read-this-first).
