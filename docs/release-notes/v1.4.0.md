A small update to Tasky, the floating dock that replaces the Windows 11 taskbar: apps now leave the dock smoothly.

> **New to Tasky? Please read [Read this first](https://github.com/Dharun1704/Tasky#read-this-first)** in the README before installing: Tasky hides the Windows taskbar while it runs (Exit Tasky always brings it back), and because it isn't code-signed, Windows SmartScreen will warn you the first time (**More info → Run anyway**).

### Downloads

| File | Size | Needs |
| --- | --- | --- |
| `Tasky-1.4.0-win-x64.zip` | ~3 MB | The [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64): `winget install Microsoft.DotNet.DesktopRuntime.10` |
| `Tasky-1.4.0-win-x64-standalone.zip` | ~65 MB | Nothing: it includes .NET |

**Updating from 1.3.0:** exit Tasky (right-click the dock → **Exit Tasky**), replace `Tasky.exe` with the one from the zip, and start it again. Your settings and pins are kept.

**New install:** unzip to a folder it can stay in (for example `%LOCALAPPDATA%\Programs\Tasky`) and run `Tasky.exe`. Windows 11, 64-bit.

### New in 1.4.0

- **Apps leave the dock smoothly.** When an app's last window closes, its icon shrinks down into the dock and fades while the icons beside it slide together, instead of vanishing and leaving the dock to jump. It follows the **Animation speed** setting.
- The icon now shrinks where it is, rather than first jumping to the end of the row.
- Unpinning an app that isn't running uses the same animation, and an app that reopens before its icon has gone simply grows back.

### Behind the scenes

- Releases are now built automatically on GitHub from the tagged code, so the downloads always match the source.

### Known limitations

Windows 11 only; one dock on one display; most apps flashing for attention don't bring up the dock (permission prompts do); Quick Settings stays bottom-right for a dock on the top or sides. The full list is in the [README](https://github.com/Dharun1704/Tasky#read-this-first).
